# gitmulti v0.0.9 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Despite its title, this release is a broad CI refresh: workflows are synced with the CLDMV/.github v4.29.2 templates, the bundle-size workflow is added, and the shared CLDMV file-header config stamps uniform comment headers across the repo. The only change to `gitmulti.js` is a comment header; no runtime code changed.

---

## 🔧 CI & tooling

### Sync with CLDMV/.github v4.29.2 templates ([#27](https://github.com/CLDMV/gitmulti/pull/27))

- Refreshes every workflow caller and `dependabot.yml`, and adds `member-auto-merge.yml` (auto-enables auto-merge on org members' PRs into `next` / `hotfixes`), `pr-notify.yml`, `provenance.yml` (SLSA provenance on release), `release-merge.yml` and `dependabot-recreate.yml`.

### Bundle-size workflow ([#29](https://github.com/CLDMV/gitmulti/pull/29))

- Adds `bundle-size.yml` and restores the full workflow list in `release-merge.yml`.

### Shared fix-headers config ([#31](https://github.com/CLDMV/gitmulti/pull/31))

- Adds `.configs/fix-headers.json` (extends `@cldmv/configs/fix-headers.json`) and a `fix:headers` script, and stamps a uniform comment header into source, test, config and workflow files. In `gitmulti.js` this is a comment block only — the code below it is unchanged.

## 🔧 Dependencies

- New dev dependencies `@cldmv/fix-headers` ^2.1.1 and `@cldmv/configs` ^1.2.0. They only affect repository tooling.
