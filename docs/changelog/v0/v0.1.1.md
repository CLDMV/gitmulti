# gitmulti v0.1.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

gitmulti is now licensed under Apache-2.0 instead of GPL-3.0. This release also fixes the release pipeline that stopped v0.1.0 from being published, and adds a pre-commit hook for contributors. No runtime code changed.

v0.1.0 merged to `master`, but its release run failed and no `v0.1.0` tag or GitHub Release was created. Everything in the [v0.1.0 changelog](./v0.1.0.md) ships for the first time with v0.1.1, including the new `gitmulti list` CLI and its breaking changes. If you're coming from v0.0.12, read the v0.1.0 upgrade notes too.

## 📜 License

- **Apache-2.0** ([#69](https://github.com/CLDMV/gitmulti/pull/69)). `LICENSE` now holds the Apache License 2.0 text, `package.json` declares `"license": "Apache-2.0"`, and the README has a License section.

## 🐛 Bug Fixes

### Release builds run on the dev Node.js floor ([#70](https://github.com/CLDMV/gitmulti/pull/70))

`publish.yml` still started its test matrix at Node.js 22.12.0, but v0.1.0 raised `devEngines` to 22.22.0 with `onFail: "error"`. So `npm ci` on the 22.12.0 leg failed with `EBADDEVENGINES` and the release stopped before publishing ([run 41944645328](https://github.com/CLDMV/gitmulti/actions/runs/41944645328)). The matrix now starts at 22.22.0, like `ci.yml`. The package's own `engines` floor stays at Node.js 22.12.0.

## 🔧 CI & tooling

- **Pre-commit hook** ([#72](https://github.com/CLDMV/gitmulti/pull/72)). `npm install` in a checkout installs `.githooks/pre-commit` into `.git/hooks/`. It runs `lint` and `format:check` and rejects the commit if either fails, without rewriting any files. The `prepare` script skips it quietly when `.githooks/` isn't present, so packing and publishing aren't affected.
- **Workflows synced to the CLDMV/.github v4.35.4 templates** ([#75](https://github.com/CLDMV/gitmulti/pull/75)). Only a human approval can arm the release merge now, and `sync-release-notes.yml` and `bot-commands.yml` are added. The type check runs as `npm run types:check`.
- **`npm run test:dist`** ([#75](https://github.com/CLDMV/gitmulti/pull/75)) runs the test suite again against the build in `dist/`, after `npm run test:cjs` checks the CommonJS entry. `npm test` runs both.

## Upgrade notes

- From v0.1.0: no breaking changes and no runtime change.
- From v0.0.12: this is the first published release with the v0.1.0 changes. You need Node.js 22.12.0 or newer, and code that called `require("gitmulti")` to run the CLI should call `require("gitmulti").run()`. See the [v0.1.0 changelog](./v0.1.0.md).
- The license is now Apache-2.0.
