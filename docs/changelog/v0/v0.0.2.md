# gitmulti v0.0.2 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

gitmulti is a small Node command-line tool for managing several repositories inside one working tree. It is meant to scan a repo for `.gitmulti` JSON files, which map files and paths to the git URL of the repository they belong to, and then commit, push and pull each underlying repo individually; it deliberately does nothing else from the git toolset. The entry point, `gitmulti.js`, is a thin [commander](https://www.npmjs.com/package/commander) program that declares `--version` and a default `list` subcommand. Versions before this one were never released (the 0.0.1 in `package.json` is the 2019 initial import).

This is the first release, and it is a repository modernization: gitmulti adopts the CLDMV `@v4` staging-branch workflow set and a `@cldmv/vitest-runner` test setup, and drops an unused dependency. No runtime code changed — `gitmulti.js` is byte-for-byte what it was in the 2019 import.

## 🔧 CI & tooling

### Adopt CLDMV @v4 workflows + vitest-runner tests ([#6](https://github.com/CLDMV/gitmulti/pull/6))

- Adds the v4 staging-branch workflow set under `.github/workflows/` (ci, publish, feature-pr, next-release, hotfixes-release, next-reset, hotfix-redirector, labeler, pr-title-normalizer, master-commit-audit, release-notify, tag-health, update-major-version-tags, v4-bootstrap, cla, codeql, scorecard, dependency-review, dependabot-auto-merge, branch-retention, stale, welcome), all thin callers of `CLDMV/.github` reusable workflows pinned `@v4`, plus `.github/dependabot.yml`.
- Adds the `@cldmv/vitest-runner` test setup: `.configs/vitest.config.mjs`, `tests/run-vitest.mjs` and two test files (`tests/gitmulti.test.mjs`, `tests/gitmulti.cli.test.mjs`) that characterize the CLI's observable behaviour. They replace the `echo "Error: no test specified"` stub.
- `package.json` scripts `test`, `test:watch`, `coverage` and `ci:coverage` are added, along with placeholder `build` / `build:ci` scripts that only echo, because the coverage job runs `npm run build`.
- Releases now go through the `next` → `master` release PR.

## 🔧 Dependencies

- **Removed unused `lodash`** from runtime `dependencies` ([#9](https://github.com/CLDMV/gitmulti/pull/9)). `git grep` at this release finds no `lodash` reference outside the lockfile — `gitmulti.js` only requires `commander` — so removing it is not a breaking change. `commander` stays at `^2.19.0`.
- **New dev dependencies** `@cldmv/vitest-runner` ^1.2.0, `@vitest/coverage-v8` ^4.1.10 and `vitest` ^4.1.10. They only affect the test and CI toolchain.
