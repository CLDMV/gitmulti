# gitmulti v0.1.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `next` → `master`

---

## Overview

gitmulti is rebuilt as an ES module on commander 15 and now has a working CLI. `gitmulti list [dir]` lists the `.gitmulti` files under a directory. The package installs a `gitmulti` executable and can also be used from code through `import` or `require()`.

This release also brings the dev toolchain up to date, pins two development-only transitive dependencies to their patched versions, and sets a Node.js floor for development and testing. Together these clear every open Dependabot alert on the repository.

---

## ✨ Features

### A working `gitmulti list` command and executable ([#68](https://github.com/CLDMV/gitmulti/pull/68))

v0.0.12 registered `list` as a separate executable subcommand that was never shipped, so running it failed. It also had no `bin` entry, and it printed a hard-coded `0.1.0` for `--version`. Now:

- `gitmulti list [dir]` is the default command. It searches `dir` (the current directory if you leave it out) and prints each `.gitmulti` file's path relative to that directory, one per line, sorted. It skips `node_modules` and `.git` folders and doesn't follow symbolic links. A path that isn't a directory exits with code 1 and prints `error: not a directory: <path>`.
- `package.json` declares a `gitmulti` executable (`bin/gitmulti.mjs`).
- `-V` / `--version` prints the real package version, and `--help` describes the command.

### Programmatic API ([#68](https://github.com/CLDMV/gitmulti/pull/68))

The package exports `findGitmultiFiles(dir)`, `createProgram({ cwd, write })` and `run(argv, options)`. Both `import` and `require()` work. The CommonJS entry is a thin wrapper that loads the ES module through Node's `require(esm)`.

## 💥 Breaking Changes

- `require("gitmulti")` no longer parses `process.argv` as soon as it loads. It now returns the API above. Call `run()` to run the CLI.
- The package needs Node.js 22.12.0 or newer (`engines.node`). commander 15 sets that floor, and so does `require()` of the ES entry.
- The `main` entry `gitmulti.js` is gone. The package ships `dist/`, `bin/` and `types/`, built by tsup.

## 🔒 Security & supply chain

- Vitest's transitive dependencies move to their patched versions, clearing the open Dependabot alerts: `vite` from 8.3.1 to 8.3.5, `@vitest/mocker` from 5.0.2 to 5.1.0, `nanoid` from 3.3.19 to 3.3.20 and `source-map-js` from 1.2.1 to 1.2.2 ([#44](https://github.com/CLDMV/gitmulti/pull/44), [#50](https://github.com/CLDMV/gitmulti/pull/50), [#60](https://github.com/CLDMV/gitmulti/pull/60), [#66](https://github.com/CLDMV/gitmulti/pull/66)). All four are development-only.
- `overrides` now force `katex` to `>=0.19.1 <1.0.0` and `minimatch` to `^11.0.3`, their patched versions ([#66](https://github.com/CLDMV/gitmulti/pull/66)). Both come in through the eslint and `@eslint/markdown` chain and are development-only.
- `npm audit` reports no vulnerabilities.

## 🔧 CI & tooling

- **Fleet package layout** ([#68](https://github.com/CLDMV/gitmulti/pull/68)):
  - Source lives in `src/`, with `src/index.mjs` and `src/index.cjs` as the entry points.
  - tsup builds `dist/` and `bin/`. Both are gitignored and rebuilt by `prepack`.
  - A `gitmulti-dev` export condition points the package at `src/` for tests.
  - `build:ci` runs lint, format check, types and build. CI uses it for builds and coverage, and the bundle-size check measures `dist/` and `bin/`.
- **Lint and format** come from `@cldmv/configs` (eslint, prettier and the jsonv plugin) ([#68](https://github.com/CLDMV/gitmulti/pull/68)).
- **Tests** ([#68](https://github.com/CLDMV/gitmulti/pull/68)):
  - The old tests pinned commander 2's output, so they were replaced.
  - The new tests cover file discovery, the CLI, the executable and the CommonJS entry, with 100% coverage.
  - A `node --test` run checks `require()` against the build.
- **Development Node.js floor.** `devEngines` requires Node.js 22.22.0 or newer, and the CI matrix starts there instead of 22.12.0 ([#66](https://github.com/CLDMV/gitmulti/pull/66)).
- `tmp/` is gitignored ([#65](https://github.com/CLDMV/gitmulti/pull/65)).

## Upgrade notes

- You need Node.js 22.12.0 or newer.
- Code that called `require("gitmulti")` to run the CLI should call `run()` instead: `require("gitmulti").run()`.
- Install the CLI with `npm install --global github:CLDMV/gitmulti`, then run `gitmulti list [dir]`.
- For contributors: working in the repository needs Node.js 22.22.0 or newer.
