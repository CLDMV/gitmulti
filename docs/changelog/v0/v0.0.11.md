## 🔧 CI & tooling

### Run the in-repo PR mirror job instead of skipping it ([#37](https://github.com/CLDMV/gitmulti/pull/37))

- GitHub does not evaluate the `name:` of a skipped job, so the previous fix showed raw expression text for the skipped job. The mirror job in `ci.yml` now always runs. On the in-repo PR path it reports under `⏭️ Required PR Check (reported by the push run)` and exits as a no-op; every status-owning path (push, fork PR, release PR) reports `✅ Required PR Check`.
