# gitmulti v0.0.4 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

A CI-only release: the `ci.yml` concurrency policy no longer lets release-relevant runs be cancelled. No runtime code changed.

---

## 🔧 CI & tooling

### Never supersede release-relevant CI runs ([#12](https://github.com/CLDMV/gitmulti/pull/12))

- `ci.yml` concurrency now gives pushes to the release base branch (from `CLDMV_RELEASE_BASE`, falling back to the default branch), pushes to `next` / `hotfixes`, and the `next` / `hotfixes` release PRs a unique concurrency group per run. Feature branches still cancel superseded runs.
- Previously a burst of pushes during a release could cancel a pending run and leave a red cancelled check on the release PR.
