# gitmulti v0.0.5 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Bot-identity wiring in three workflow callers plus a patch-level bump of the test toolchain. No runtime code changed.

---

## 🔧 CI & tooling

### Wire bot identity into release workflows ([#16](https://github.com/CLDMV/gitmulti/pull/16))

- `feature-pr.yml`, `next-release.yml` and `hotfixes-release.yml` now pass `BOT_NAME` / `BOT_EMAIL` (from `CLDMV_BOT_NAME` / `CLDMV_BOT_EMAIL`) so bot-authored commits and PRs use the real bot identity.

## 🔧 Dependencies

### Patch group bump ([#15](https://github.com/CLDMV/gitmulti/pull/15))

- `vitest` and `@vitest/coverage-v8` 4.1.10 → 4.1.11. Both are dev dependencies and only affect the test/CI toolchain; the `package.json` range for `@vitest/coverage-v8` moved to `^4.1.11` and the lockfile resolves both to 4.1.11.
