# gitmulti v0.0.6 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

A single CI change: `hotfix-redirector.yml` now passes the bot GPG secrets. No runtime code changed.

---

## 🔧 CI & tooling

### Sign redirected security PRs ([#18](https://github.com/CLDMV/gitmulti/pull/18))

- `hotfix-redirector.yml` maps `BOT_NAME`, `BOT_EMAIL`, `BOT_GPG_PRIVATE_KEY` and `BOT_GPG_PASSPHRASE` so Dependabot security PRs redirected away from `master` are cherry-picked as signed commits; unsigned ones were blocked by the signature rule.
