# gitmulti v0.0.10 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

The release title names a coverage-v8 bump, but the release also carries a vitest-runner bump and a fix to the `ci.yml` Required PR Check job. No runtime code changed.

---

## 🔧 CI & tooling

### Stop the skipped PR-run mirror from satisfying Required PR Check ([#36](https://github.com/CLDMV/gitmulti/pull/36))

- On an in-repo feature PR the `pull_request` run skipped the `✅ Required PR Check` mirror job, and GitHub treats a skipped required check as passing, so a PR could become mergeable before the push run's tests finished. The job name in `ci.yml` became an expression so the skipped job no longer posts under the required name (see [CLDMV/slothlet#553](https://github.com/CLDMV/slothlet/issues/553) for the original incident).

## 🔧 Dependencies

- `@vitest/coverage-v8` 5.0.1 → 5.0.2 ([#33](https://github.com/CLDMV/gitmulti/pull/33)) and `@cldmv/vitest-runner` 1.2.0 → 1.5.1 ([#34](https://github.com/CLDMV/gitmulti/pull/34)). Both are dev dependencies and only affect the test/CI toolchain. `package.json` ranges moved to `^5.0.2` and `^1.5.1`; the lockfile also resolves `vitest` to 5.0.2.
