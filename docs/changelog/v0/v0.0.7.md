# gitmulti v0.0.7 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

The Node CI matrix and the test toolchain move to vitest 5. Only workflow files, `dependabot.yml` and dev dependencies changed; no runtime code changed.

---

## 🔧 CI & tooling

### Node CI matrix for vitest 5 ([#22](https://github.com/CLDMV/gitmulti/pull/22))

- `ci.yml` and `publish.yml` default `min_node_version` moves from `20` to `22.12.0` (the floor vitest 5 runs on) and `max_node_major` from `22` to `26`.
- `.github/dependabot.yml` gains `vitest`, `eslint` and `prettier` groups so packages that peer each other exactly are bumped together.

## 🔧 Dependencies

### vitest 5 ([#20](https://github.com/CLDMV/gitmulti/pull/20))

- `vitest` and `@vitest/coverage-v8` 4.1.11 → 5.0.0, both dev dependencies that only affect the test/CI toolchain. The `package.json` ranges and lockfile both moved to 5.0.0.

## Upgrade notes

- No breaking changes — drop-in for v0.0.6. No runtime code changed. Running the repository's own tests now needs Node 22.12.0 or newer.
